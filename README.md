# harrison shin

Personal site for Harrison Shin — educator, builder, stoic, working in higher ed in Irvine, CA. One static page: a starfield, a short line of bio, link pills, and ko-fi / base support chips. Plain HTML, CSS, and JavaScript, with Inter loaded from Google Fonts.

## Deploy

The site is the repository root (`index.html`, favicons, and `og-image.png`). There is no build step. `.nojekyll` is included so GitHub Pages skips Jekyll and publishes the files as they are.

Image and icon URLs in the page are relative, so the same files work on the project site:

https://dharrisonshin.github.io/harrisonshin/

Open Graph tags stay on absolute `https://harrisonshin.com` URLs. This repo has no `CNAME`; add one only after `harrisonshin.com` is pointed at GitHub Pages.
